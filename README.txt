# نظام ريدان لإدارة الدلفري — نسخة مجانية

## التشغيل
1. أنشئ مشروع Supabase مجاني.
2. افتح SQL Editor والصق محتوى `supabase.sql` ثم Run.
3. من Project Settings > API انسخ Project URL و anon/public key.
4. افتح `app.js` وضعهما مكان:
   YOUR_SUPABASE_URL
   YOUR_SUPABASE_ANON_KEY
5. ارفع الملفات إلى GitHub Pages أو أي استضافة Static مجانية.

## الصفحات
- `index.html` واجهة الآيباد للكاشير.
- `admin.html` لوحة التحكم.
- نفس قاعدة البيانات تستخدمها الواجهتان مع Realtime.

ملاحظة: هذه النسخة لا تحتوي دفع إلكتروني.
